JAYDEN DANIELS FAN PAGE

Files:
- index.html (home page)
- photos.html (photo gallery)
- style.css (colors, font, layout)

To preview:
Open index.html in your browser and click Home or Photos at the top.
Internet access is required for the Wikimedia Commons photos, Google font and YouTube video.

To publish using GitHub Desktop:
1. Unzip this folder.
2. In GitHub Desktop choose File > Add Local Repository.
   If needed, choose Create a Repository from the folder, name it jayden-daniels-fan-site and make sure it contains index.html at the top level.
3. Click Publish repository. Uncheck Keep this code private if the box is checked.
4. On GitHub.com open the repository > Settings > Pages.
5. Under Build and deployment select Deploy from a branch.
6. Select main and / (root), then Save.
7. After GitHub finishes publishing, click Visit site on Settings > Pages.
8. Submit that URL to your instructor.

Typical URL:
https://YOUR-USERNAME.github.io/jayden-daniels-fan-site/

If you use a different repository name, the URL changes too.
